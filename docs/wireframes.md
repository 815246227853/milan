# Wireframes

Milan has three places. Functions (haldi, sangeet…) are labels, not sections.

| Screen | Purpose |
|---|---|
| Set up the wedding | Date, city, guests, budget, functions, and the vendor list Milan will call (upload a sheet or add by hand) |
| Home | Countdown, "Give Milan a job", Needs you, Milan is working on, functions, budget, today's activity |
| Give Milan a job | The request, Milan's plan, the comparison and recommendation; calls and transcripts on the side |
| Approve a decision | Right side sheet: what changed, the cost, which rule asked (Flagsmith), what happens if you approve |
| Vendors | One table for everyone; the selected vendor's deal, calls and next step beside it |
